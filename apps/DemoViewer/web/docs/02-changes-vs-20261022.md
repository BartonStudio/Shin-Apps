## 没变的（架构稳定）

- 解析链路：`.dem` → sha256 缓存键 → IndexedDB 命中/未命中 → worker → wasm → SoA → 插值播放
- 采样率三档 16/32/64 Hz（默认 32）
- 地图来源 `maps.csdemo.tv`、比赛目录 `data.csdemo.tv`
- CSDA 容器格式、IndexedDB 库 `csplayer`、localStorage 前缀 `csdemo:` / `csplayer:`
- 无框架、纯 DOM + 模板字符串、无统计/广告
